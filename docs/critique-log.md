## Блок 1 — DESIGN-SYSTEM.md (14.10.2026)

**Специфичность: 8/10.** Идею не скопировать конкуренту: хромовый пион отражает реальные залы, зеркала взяты с фасада Пушкина, пионы — со стен студий. Слабое место: само поле сирени/пиона без хромового объекта выглядит как «цветочный» сайт по умолчанию. Значит, держит всё не цвет, а объект и фото.

| # | Приоритет | Проблема | Исправление |
|---|---|---|---|
| 1 | P0 | Не было числовых проверок контраста, стояли округлённые «на глаз» цифры | Пересчитано по WCAG и исправлено в §9; `peony-deep` ограничен крупными формами (4.4:1) |
| 2 | P0 | WebGL-цветок без спецификации геометрии и бюджета на телефоне: два разработчика сделают разное | Геометрия, материал, бюджет и запасной вариант вынесены в TZ.md §6.1 |
| 3 | P1 | Слишком много «фирменных» приёмов (цветок, лента, диафрагмы, шторка, цветок в строке) — риск каши | Иерархия зафиксирована: громкий только цветок, остальное тихое. Лент — максимум 2, «цветок в строке» — только в интро |
| 4 | P1 | Логотип #6B3721 (коричневый) спорит с холодным перламутром | Монохромная версия `plum`/`pearl`; коричневый — только фавиконка/OG. Внесено в открытые вопросы — согласовать с салоном |
| 5 | P1 | Вшитый текст на фото акций ломает систему «текст поверх чистого фото» | Запрос чистых исходников; временное кадрирование — в TZ.md §5.2 |
| 6 | P2 | Unbounded часто встречается на русских сайтах 2024–2026 | Оставлено: строчный светлый 200–300 с плотным трекингом ощутимо отличается от типичного жирного капса. Запасной вариант — Geologica |
| 7 | P2 | «Пилюля всё» (кнопки, чипы, теги) может выглядеть шаблонно | Пилюля — только интерактив и теги; панели — радиус 32px, медиа — круг. Три формы, у каждой своя роль |

**Сильные стороны:** реальный материал студий вместо стока; цены текстом с уровнями мастера; одна «живая вещь» (переключатель студии), которая влияет и на эффект, и на запись.

**Slop-проверка (house rules Taste):** надзаголовков нет · моноширинного нет · нумерации 01/02 нет · тонких линий нет · градиентов в UI нет (хром — материал 3D, скрим под подписями — разрешённое исключение) · теней в покое нет · стекла нет (исключение для меню убрано: меню — сплошное поле `peony`) · гарнитур две.

## Блок 2 — Шапка, меню, состояние студии, шторка записи (TZ.md §4) (14.10.2026)

Method: dual-agent (A: design review · B: detector/evidence), два изолированных субагента. Браузерной проверки нет (нет инструмента автоматизации браузера в этой сессии) — обе оценки это явно декларируют; A читает код, B гоняет детектор + механические проверки.

**Design Health Score: 28/32 (87.5%, Good)** — 8 эвристик Nielsen применимо, #7 (Flexibility) и #10 (Help) n/a для этого Persuade-блока.

**Специфичность: высокая, не каталожная.** `ButtonPrimary` воспроизводит приём «стрелка в круге» из DESIGN-SYSTEM.md §9 буквально (translate 2px/-2px, scale 1.05, 160ms); `MobileMenu` считает точку раскрытия клипа от реального места тапа по кнопке — не стоковая шторка; `BookingSheet` — единственная тень во всём слое, именно там, где спецификация её разрешает.

**Детектор:** `impeccable detect --json` по всем 8 файлам — 0 находок. Механические проверки (B): анимируются только transform/opacity/clip-path/background-color; нет hex мимо токенов (кроме намеренной замены в `Logo.astro`); все интерактивные элементы имеют доступное имя; оба `<dialog>` — с `aria-label`, Escape и закрытием по фону. Детектор и дизайн-разбор не противоречат друг другу: код чистый, проблемы — в переходах состояний, которые статический сканер не видит.

| # | Приоритет | Проблема | Исправление |
|---|---|---|---|
| 1 | P1 | Скрытая шапка (`translateY(-100%)`) остаётся в табе клавиатуры — фокус проваливается на невидимые ссылки | Добавить `inert`, когда `data-hidden="true"` |
| 2 | P1 | Выбор студии в шторке открывает блок CTA без скролла/фокуса — на низком мобильном экране кнопка может уйти за край | Скроллить открывшийся блок в вид при выборе |
| 3 | P2 | После клика по якорю в мобильном меню фокус не передаётся на целевую секцию | Переносить фокус на заголовок секции после закрытия диалога |
| 4 | P2 | CTA и ссылки мессенджеров в шторке по умолчанию `href="#"` до JS — при сбое загрузки скрипта превращаются в мёртвые ссылки без сообщения | Прописать реальный fallback-href в разметке заранее |
| 5 | P3 | 6 пунктов мобильного меню равны по весу — «акции»/«цены» не читаются как более важные | Выделить два денежных пункта размером/весом |

**Персоны:** Casey (моб.) — шапка прячется после 120px скролла, а «вечная» sticky-CTA из §5.1 появится только на следующем шаге, так что в середине скролла сейчас нет пути к записи. Jordan (новичок) — шторка открывается без подсказки «выберите студию». Sam (доступность) — переключатель студии и список студий в шторке моделируют взаимоисключающий выбор как независимые `aria-pressed`, а не `radiogroup`.

**Решение:** находки записаны, фиксы не блокируют пуш Шага 2 (TZ.md допускает это: «шаг закончен = критика записана»); P1/P2 перенесены в бэклог на один из следующих шагов по решению пользователя.

## Блок 3 — Шаг 4: хромовый пион (TZ.md §6.1) (15.10.2026)

Method: dual-agent (A: design review · B: detector/evidence), два изолированных субагента. Браузерной проверки нет — рендер, FPS и потеря контекста не проверены вживую.

**Design Health Score: 24/32 (75%, Good)** — #7 и #10 n/a (Persuade). Сильнее всего просели #4 Консистентность (2: SVG-fallback визуально «другой сайт») и #9 Восстановление (1: потеря контекста не обработана).

**Специфичность: высокая по замыслу** — процедурный пион, золотой угол, iridescence, env из реальных фото студий, кроссфейд при смене студии. Fallback пока шаблонный (плоский SVG).

**Детектор:** `impeccable detect --json src/` — 0 находок, ложных нет. Только transform/opacity/clip-path/background-color; цвета в CSS — токены (0xf2eef6/0xffffff в JS — материал 3D, не CSS). Бюджет 57 600 треугольников (≤60k, запас ~4%). Чанк three 688 КБ / 177 КБ gzip, ленивый. `/thegarden/env/*.jpg` отдаются 200.

| # | Приоритет | Проблема | Исправление |
|---|---|---|---|

| 5 | P2 | Нет интерактива §5.1/§6.2: наклон от курсора ±8°, поворот 40° и опускание 10vh при скролле | Добавить в шаге 11 (движение целиком) |

**Персоны:** мобильная клиентка на среднем Android — рывки при смене студии и потеря контекста при возврате из мессенджера; слабое устройство/reduced-motion — доступно, но «не хром»; a11y — canvas `aria-hidden`, смысл несёт текст, ок.

**Решение:** шаг закрыт, P1 не блокируют пуш; P1 (1–2) предлагаю исправить до шага 5.
