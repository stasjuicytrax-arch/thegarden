## 1. Задача и рамки

Новый сайт студии красоты The Garden: две студии (Пушкин — флагман, Фрунзенская — Санкт-Петербург). Задача сайта — довести посетительницу до записи в 1–2 касания, показать полный прайс текстом и акции месяца с датами.

- **ЦА:** клиентки 25–45 лет из Пушкина и юга СПб, в основном с телефона, часто приходят из VK/Telegram.
- **Тон:** ультрасовременный, модный, много анимации, вау-эффект с первого экрана.
- **Структура:** со старого сайта thegardenstudio.ru, без выдуманных разделов. Порядок блоков сохранён (§3).
- **Не делаем:** онлайн-оплату, личный кабинет, свою форму записи (запись — YCLIENTS и мессенджеры), блог, отзывы (их нет — не выдумывать).

## 2. Стек и структура проекта

- **Astro 5** (статическая сборка), TypeScript, без UI-фреймворка (компоненты `.astro`, островки на ванильном TS).
- **GSAP 3.13+** (ScrollTrigger, SplitText), **Lenis** — плавный скролл. WebGL и three.js не используются (решение 15.10.2026).
- Стили: обычный CSS с custom properties из `DESIGN-SYSTEM.md` (без Tailwind; токены в `src/styles/tokens.css`).
- Шрифты: Unbounded и Jost, только кириллица+латиница, `woff2` локально в `public/fonts/`, `font-display: swap`, preload двух начертаний первого экрана.
- Картинки: `astro:assets` → AVIF/WebP, `srcset`.
- Хостинг: статический (Netlify/Vercel/свой сервер — уточнить). Сборка `npm run build` → `dist/`.

## 4. Глобальные элементы

### 4.1 Шапка
- Desktop: высота 72px, поле `pearl`. Слева логотип (`assets/brand/logo.svg`, монохром `plum`, высота 36px) → `#top`. По центру ссылки: **Акции · Цены · Студии · Контакты**. Справа: телефон `+7 (812) 317-77-78` (от 1280px), кнопка «Записаться».
- При скролле вниз больше 120px шапка уезжает вверх (translateY), при скролле вверх возвращается. Активный якорь подсвечивается точкой 6px `plum` под ссылкой.
- Mobile (<768): логотип 28px, кнопка «Записаться» (компактная, 44px), круглая кнопка меню 44px.

### 4.2 Мобильное меню
Полноэкранное, сплошное поле `peony`. Пункты Unbounded 300, 11vw: акции, цены, студии, работы, лояльность, контакты. Ниже — телефон, иконки Telegram/WhatsApp/MAX выбранной студии, VK. Появление: поле раскрывается кругом из кнопки меню (clip-path circle, 640ms), пункты поднимаются с шагом 70ms. Иконка «бургер» превращается в крест (две линии, поворот ±45°). Закрытие — Esc, крест, тап по пункту. Фокус заперт внутри меню.

### 4.3 Состояние «выбранная студия»
- Глобальное состояние `studio = 'pushkin' | 'frunzenskaya' | null` в `studio-state.ts`, хранится в `localStorage` (`tg-studio`), обёрнуто в try/catch.
- По умолчанию `null`: кнопки «Записаться» открывают шторку выбора (§4.4).
- Меняет: отражение в цветке, адрес и мессенджеры в меню, в «Связи» и в контактах (выбранная первой), ссылки кнопок записи, фильтр дат акций.
- Переключатель — компонент `StudioSwitch`: сегмент «Пушкин | Фрунзенская» (пилюля, активный чип ползёт FLIP 320ms). Стоит в первом экране, в блоке акций, в шторке записи.

### 4.4 Шторка записи (BookingSheet)
Открывается любой кнопкой «Записаться». Desktop — панель 480px справа поверх страницы; mobile — нижняя шторка 88svh, тянется пальцем вниз для закрытия.
Содержимое:
1. Заголовок heading-2: «записаться».
2. Выбор студии — две крупные строки-кнопки с круглым фото (pushkin/02, frunzenskaya/03), адресом и «ежедневно 10:00–21:00».
3. После выбора: основная кнопка «Онлайн-запись» (YCLIENTS студии), ниже вторичные кнопки Telegram · WhatsApp · MAX этой студии, телефон.
4. Если кнопка вызвана из акции — в шторке строка «Акция: −15% Маникюр «Всё включено»» и даты для выбранной студии.
- Ссылка YCLIENTS: общая `https://n111177.yclients.com/select-city?o=` (выбор города внутри YCLIENTS); как только салон пришлёт прямые ссылки филиалов — подставить в `site.json` (`booking`). Если YCLIENTS разрешает виджет — можно открыть его во фрейме внутри шторки (решение после проверки, см. §13).
- Esc / тап по фону / свайп вниз закрывают. Фокус заперт.

### 4.5 Плавная прокрутка и якоря
Lenis на всём сайте (кроме `prefers-reduced-motion`). Переход по якорю — `lenis.scrollTo(target, { offset: -72, duration: 1.2 })`.

**Цель:** вау с первой секунды + понять «студия красоты, две студии, записаться».

- В центре: «зеркало-диафрагма» — круг `peony` с фото интерьера выбранной студии (§6.1).
**Композиция desktop (1440×900):** заголовок по центру, полоса 11–40% высоты, строки строчными в две строки; под ним по центру плоский круг `peony` ~60vw, внутри которого фото интерьера выбранной студии (круг фото чуть меньше, по краю остаётся кольцо поля). Низ строки перекрывает верх круга. Лид в колонке 280px, низ-лево, базовая линия 32px от низа; переключатель и кнопка — низ-право на той же базовой линии. Фон `pearl`.
**Mobile (390×844):** заголовок в верхней трети по краям 16px; круг ~94vw по центру; лид и переключатель под кругом; кнопка «Записаться» фиксирована внизу экрана (sticky CTA 56px) — остаётся на всех экранах на мобильном.
**Движение:** §6.2 «Загрузка». Скролл первого экрана (ScrollTrigger, pin hero, `end: +=100%`, `scrub: 0.8`): `clip-path` круга растёт от исходного радиуса до полного экрана, фото масштабируется 1.15 → 1, заголовок и лид уходят вверх с opacity 0; в конце — полноэкранное фото студии, затем пин отпускается. Смена студии — кроссфейд двух фото 600ms.
**Приёмка:** первый экран полностью на 1280/1440/1600/390; LCP-элемент — заголовок (текст); фото в круге — avif/webp через `astro:assets`; при `prefers-reduced-motion` пина и анимаций нет — статичный круг с фото.

2. Справа (колонки 6–12): витрина акций — по одной в строке, чередуя сторону фото:

## 6. Сигнатура и движение

### 6.1 Зеркало-диафрагма (первый экран)
- **Конструкция:** контейнер `.hero__disc` на весь hero с `clip-path: circle(r at 50% 58%)`; внутри два слоя-фото (`pushkin/02`, `frunzenskaya/03`), активный — `opacity: 1`, второй — `0`. Позади плоский круг `peony` ~60vw (радиус фото ≈ 0.86 от него).
- **Радиус:** исходный `min(25.8vw, 387px)` (мобильный `47vw`); на скролле растёт до расстояния до дальнего угла hero. Значения задаёт `hero.ts` через переменную `--r` (px), в CSS — запасное значение до JS.
- **Скролл:** GSAP ScrollTrigger на hero, `pin: true`, `start: top top`, `end: +=100%`, `scrub: 0.8`. Анимируются только `clip-path` (через `--r`), `transform: scale` фото (1.15 → 1), `transform`/`opacity` заголовка и лида.
- **Смена студии:** `onStudioChange` переключает активное фото, кроссфейд 600ms (CSS `transition: opacity`).
- **Изображения:** `astro:assets` `<Picture>`, форматы avif/webp, ширины 768/1280/1920, `sizes="100vw"`; первое фото `eager`, второе `lazy`. Декоративные (`alt=""`, контейнер `aria-hidden`).
- **Reduced motion:** без пина, без анимации радиуса и load-последовательности; кроссфейд без transition.
- **Производительность:** никакого WebGL/three.js; вес первого экрана — два avif/webp; ни одного скриптового рендера.

### 6.2 План движения
| Где | Что | Параметры |
|---|---|---|
| Загрузка | строки заголовка поднимаются из-под базовой линии | SplitText lines + маска, 1100ms ease-out, шаг 110ms |
| Загрузка | цветок поднимается и раскрывается | 1800ms, старт через 300ms после заголовка |
| Загрузка | лид, переключатель, кнопка | fade + 28px, 640ms, шаг 70ms |
| Все секции | заголовок → текст → медиа | ScrollTrigger once, 28px + opacity, шаг 70ms |
| Фото | диафрагма | clip-path circle 0→75% + scale 1.08→1, 1100ms |
| Смена полей | фон секции pearl ↔ peony | 640ms при пересечении 40% вьюпорта |
| Ленты (2 шт.) | бегущая строка | 40px/с × (1 + |v|/1000), направление от скролла |
| Акции | скидка-счётчик, FLIP при фильтре | 600ms / 320ms |
| Прайс | FLIP высоты листа | 320ms ease-in-out |
| Галерея | шторка sticky, параллакс мозаики | без перехвата скролла |
| Подвал | вордмарк поднимается | scrub по последним 50vh |
| Кнопки | наведение / нажатие | 160ms; scale 0.98; круг со стрелкой +2px ↗ и scale 1.05 |
| Курсор (desktop) | — | системный, без кастомного курсора |

Reduced motion — `DESIGN-SYSTEM.md` §8. Анимируются только transform / opacity / clip-path / background-color.
